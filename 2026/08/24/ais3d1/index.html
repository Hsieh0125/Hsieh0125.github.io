Web

題目如下

Command Injection-1

打開之後是一個WebShell

試著輸入a之後 發現它的執行方式是

所以可以使用;阻斷之後 即可正常使用指令 輸入pwd之後 發現目前在/app目錄 隨後先回到根目錄查看是否有Flag

Flag確實在根目錄 所以再加一個cat flag就好

Command Injection-2

一樣先輸入a 查看Shell爆出甚麼 發現在Shell裡面會是這樣

所以一樣使用拚接技巧

Command Injection-3

一樣是個WebShell 但沒有欄位可以輸入 所以先F12

把hidden屬性刪除 然後重整 輸入欄位就會出現

一樣要用拼接方式 每次重整都需要F12刪除hidden屬性 所以一樣先pwd 然後回根目錄

看到flag.txt了

發現了secret_notes 而且有看到flag在裡面 所以接著檢查它

把name改成flag 其他的改成NULL (欄位要對齊)

Path Traversal

一樣先試試輸入a 觀察Shell的輸出

Path Traversal-2

所以使用URL encode替代字元 “.”用%2e替代 “/“則是%2f

File Upload-1

打開之後 是一個上傳檔案的地方 然後有提示 這跟php有關 所以我參考了這裡所示範的Payload

存成php檔案之後 上傳到Server

然後複製路徑 貼到URL後面 然後在php?後面接cmd=

這時候我們就可以自由查看目錄中的檔案 然後題目有給hint 叫我們注意某個目錄

所以先查看該目錄的檔案

看到flag.txt了

File Upload-2

跟上一題一樣 但前端不能上傳php 所以必須開Burp

先把upload.jpg上傳 然後在burp裡面查看被攔截的封包 然後把附檔名改成.php 這樣就可以成功送出了

接下來就是跟第一題一樣 找到/var/www/html 然後找到flag.txt

這裡要注意的一點是 每次從瀏覽器端送出請求 burp就會攔截 所以每次都要回burp按Forward

Flag就出現了
